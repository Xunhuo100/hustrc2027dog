# HUSTRC_2027_DOG
2027年狗子的主控代码

## 结构
修改自unitree_guide的FSM结构，将其底层机制从ROS1+GAZEBO修改为ROS2，与控制逻辑和仿真解耦

底层控制在'src/robot_ctrl/src/interface/RobotIO.cpp',向'motor_command_topic'发布电机控制指令(sim，要上实机在这里加电机直接控制那一套，或者另外写一个电机工作包)，向'motor_state_topic'读取电机反馈数据和IMU数据等，深度相机暂时没用

主要的控制调度写在robot_ctrl

主要的代码流程是：控制器启动后进入 Passive。一键启动时，策略节点在收到有效机器人反馈后，通过 /robot/mode 请求进入 Stand，等待站立阶段后再请求进入 RL；控制器负责检查切换条件和执行保护逻辑

控制节点通过 RobotIO 发布机器人状态，策略节点接收状态和期望速度并输出电机目标；进入 RL 后，控制器使用这些策略指令(策略部署的包：himloco_sim2sim)

wheel_leg_mujoco是go2w的MUJOCO仿真包，理论上是通用的，提供电机数据和IMU、相机的反馈数据，搭建场地障碍以及机器人模型及其执行，主控节点与之通讯

himloco_policy是himloco的策略部署，这里和主控通讯，获取观测的数据。理论上后面部署其他模型也是类似的接口



## 使用
目前是用键盘控制，用键盘输出期望的速度，狗子跟踪之

直接用脚本启动

`start_sim.sh` 默认开启观察视角跟随，启用键盘控制，注视点跟随机器人机身；可用鼠标旋转、缩放，视角不随机身翻滚。
